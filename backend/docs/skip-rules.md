# 自动任务的"不做无意义操作"规则（2026-11-02 补充）

> 用户原则：**当天没有录音文件就不应该做任何多余操作**（尤其是不调用大模型、不推送）。

## 判定规则（三处入口统一收紧）

| 场景 | 行为 |
|---|---|
| 当天**没有任何上传文件** | 跳过，**不调用 LLM**，不生成空日记，**不推送** |
| 有上传但**没有任何可用转写文本**（全部失败/空白） | 跳过，**不调用 LLM**，不推送 |
| 有转写文本、**当天日记已存在** | 定时任务只补推送，**不重复调用 LLM** |
| 有转写文本、日记不存在 | 正常生成 → 推送 |
| 手动调用 `/api/summarize` 传一个无数据日期 | 返回明确错误，不落任何脏数据 |
| 手动调用 `/api/push/{date}` 但该日无日记 | 返回「还没有总结，不推送」 |
| 转写 worker 空闲（无待转写文件） | 只做一次空查询后 sleep，不轮询 ASR、不打日志轰炸 |

## 实现位置

| 位置 | 代码 |
|---|---|
| 定时总结 | `main._run_daily_summary()` 前置判断 `transcripts_for_day` + 文本非空 |
| 生成总结（所有入口共用） | `main.summarize_date()` 前置判断，无数据直接抛错，不写 `journals` |
| 推送 | `main.do_push()` 检查存在 + `status=done` + 内容非空 |
| 转写队列 | `transcribe._loop()` 无待处理即 `Event.wait(15)` 等待唤醒 |
| 前端提示 | 总览「上次总结」在无数据跳过时显示 `无录音，已跳过` 徽标 |

调度状态里记录 `last_run.summary_has_data`，便于在后台看出这次定时任务是"真跑了"还是"跳过了"。

## 验证结果

```
=== 总结一个没有录音的日期 ===
{"ok":false,"error":"2025-01-01 没有录音/转写内容，已跳过（不调用大模型）"}

=== 推送一个没有日记的日期 ===
{"ok":false,"error":"2025-01-02 还没有总结，不推送"}

=== 定时任务：无录音日期 ===
[sched] 2025-01-01 无录音/转写，跳过总结与推送（不做无意义的 LLM 调用）

=== 定时任务：有录音日期 ===
[sched] 2026-11-02 已有总结，仅推送
```

> 注：现有日记（2026-11-02）状态保持 `done`，`push_status={"bark":"ok"}`，Bark 记录 `http=200`，功能未回归。

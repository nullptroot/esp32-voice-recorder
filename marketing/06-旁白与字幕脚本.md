## 2. 为什么这么写

| 写法 | 用意 |
|---|---|
| 开头不铺垫，直接上价格 | 抖音前 2 秒决定完播率 |
| 「六十五块做了一个」而不是「仅需 65 元」 | 口语化，像跟朋友说 |
| 痛点用三个短句并列 | 每句一个卡片，节奏刚好踩上转场 |
| 「它不是录音笔」先否定 | 制造认知差，让人想听下去 |
| 数字全部具体（三十五块九） | 具体数字比「几十块」可信 10 倍 |
| 焊接段说「后面全是玄学」 | 自嘲，拉近距离，也解释了为什么要认真焊 |
| 翻车段用「当然也翻车了」 | 主动示弱，比全程成功更真实 |
| 结尾「点个星」不说「求关注」 | 开源社区的语感，不俗气 |

## 3. 配音建议

**语气**：克制、有点兴奋，像跟朋友分享「我搞出来了」。不要播音腔、不要喊麦。

**重音**：

| 位置 | 重读 |
|---|---|
| S01 | 六七百 / 六十五 |
| S04 | 三十五块九 / 一共不到七十 |
| S05 | 三百五十度 / 玄学 |
| S10 | 电压不够 / 根本没在 RTC 域 |
| S12 | 全部开源 |

**停顿**：

| 位置 | 处理 |
|---|---|
| 「六七百的录音豆，」后 | 0.2s，制造落差 |
| 「做了一个。」后 | 0.3s，再接痛点 |
| 「它不是录音笔。」后 | 0.25s |
| 「当然也翻车了。」后 | 0.3s，语气松下来 |
| 「全部开源，」后 | 0.2s，收尾上扬 |

**参数**：见 `narration/README.md`（S2 Pro 语速 1.0–1.06、48kHz WAV、统一 -16 LUFS）。
**校验**：生成后跑 `python3 marketing/tools/check_voice_durations.py`，±15% 内直接可用。

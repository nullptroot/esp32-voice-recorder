# Remotion 视频制作提示词（竖屏 9:16 · 115s 主片）

> **怎么用**：把下面「一、任务」到「九、验收」整段复制给 AI（Claude Code / Cursor / ChatGPT 均可），
> 并把 `marketing/assets/` 和 `marketing/narration/` 一起给它。
> 配音文本在 `narration/`，一个场景一个 txt，已处理成 TTS 可直接朗读的版本。

## 一、任务

用 **Remotion 4.x + TypeScript** 制作一条 **115 秒竖屏 9:16** 的产品宣传片，项目名 `recbean-promo`。

主题：**「市面 600~700 的录音豆，我花 65 块自己做了一个，而且完全开源。」**

片子要给谁看：抖音 / 小红书上的**硬件 DIY、开源、AI 工具**爱好者。
目标不是「功能罗列」，而是让人看完产生三个反应：
1. 「65 块？真的假的」→ 好奇
2. 「它居然能自己醒、自己录、自己传」→ 理解
3. 「代码开源，我也想搞一个」→ 行动

交付物：
- 一条 115s 主片（1080×1920 / 30fps / 3450 帧）
- 一张封面静帧（第 0 帧，可直接当抖音封面）
- 一条 45s 短版（见附录 A，同一套场景裁剪）

## 二、硬性规格

| 项 | 值 |
|---|---|
| Composition ID | `RecBeanPromo` |
| 分辨率 | 1080 × 1920（9:16） |
| 帧率 | 30 fps |
| 时长 | 115.0s = **3450 帧** |
| 编码 | H.264 / yuv420p / CRF 18 |
| 语言 | 简体中文（字幕 + 大字），可留英文小字点缀 |
| 输出 | `out/recbean-promo.mp4`，目标 < 100MB |

**安全区（必须遵守，抖音/小红书 UI 会挡）**：

- 顶部留 **220px**，底部留 **320px**，左右各留 **80px**
- 所有文字必须落在安全区内；装饰元素可以出血
- 字幕基线不高于 y=1600，字号 56~72px，单行 ≤ 12 个汉字，最多 2 行

**节奏硬约束**：

- 前 3 秒必须有 3 次以上视觉变化（价格卡 / 划掉 / 数字爆炸）
- 全片**任何静止画面不超过 2.5 秒**（缓推、位移、闪烁都算动）
- 转场以**硬切**为主，最多 3 次 0.12s 白闪 / 横向扫过；**不要** 3D 翻页、粒子爆炸、镜头光晕滥用

## 三、视觉系统

```ts
// src/theme.ts
export const C = {
  bg:      '#0A0B0D',   // 深空黑
  panel:   '#15181C',   // 卡片底
  line:    '#2A3038',   // 描边
  text:    '#F2F5F7',   // 主文字
  dim:     '#8A939E',   // 次要文字
  cyan:    '#00E5C0',   // 科技/正确/成功
  orange:  '#FF7A1A',   // 便宜/自造/强调
  red:     '#FF3B30',   // 问题/价格/错误
  green:   '#38D97A',   // 修复/完成
};
```

- **字体**：`@remotion/google-fonts/NotoSansSC`，字重 700 / 900；数字用 `BebasNeue` 或 `Oswald` 做价格/计数。
- **背景**：深空黑 + 极淡网格（`opacity 0.18`）+ 缓慢漂移（每帧位移 0.05px），全片统一，营造「工程感」。
- **卡片**：圆角 24px，`backgroundColor: C.panel`，`border: 1px solid C.line`，内边距 40px。
- **强调**：关键词单独换色 + `scale` 弹一下（spring，damping 200），不要整段变色。
- **禁止**：纯白底、渐变紫蓝「AI 风」、emoji 堆砌、超过 3 种主色同屏。

## 七、工程结构与实现要求

```
recbean-promo/
├── public/
│   ├── assets/…            # 从 marketing/assets 拷入
│   └── audio/              # vo-01..12.wav, bgm.mp3, sfx/*.mp3
├── src/
│   ├── index.ts            # registerRoot
│   ├── Root.tsx            # Composition: RecBeanPromo / RecBeanPromo45
│   ├── theme.ts
│   ├── config.ts           # SHOT_READY / AUDIO_READY / FIT / SAFE
│   ├── components/
│   │   ├── Backdrop.tsx    # 网格 + 漂移 + 暗角
│   │   ├── Caption.tsx     # 安全区字幕，2 行，自动换行
│   │   ├── BigText.tsx     # 大字，逐字上浮
│   │   ├── CountUp.tsx     # 数字滚动
│   │   ├── KenBurns.tsx    # 静帧缓推
│   │   ├── PhoneFrame.tsx  # 手机外框
│   │   ├── Tag.tsx         # 胶囊标签
│   │   ├── OrderWall.tsx   # S04 订单墙（2×2，错位）
│   │   ├── BugCard.tsx     # S10 卡片（含打字机）
│   │   └── ProgressRow.tsx # S11 进度条
│   └── scenes/
│       ├── S01Hook.tsx  …  S12CTA.tsx
```

实现约束：

1. 每个 Scene 导出 `{ durationInFrames, component }`，由 `Root.tsx` 用 `<Series>` 拼接，**不要**把所有逻辑塞一个文件。
2. 动画统一用 `spring({ frame, fps, config: { damping: 200, mass: 0.6 } })` 和 `interpolate(..., { easing: Easing.out(Easing.cubic), extrapolateLeft: 'clamp', extrapolateRight: 'clamp' })`。
3. 所有时间以**帧**为单位，禁止 `setTimeout` / CSS `animation`。
4. 中文字体通过 `loadFont()` 加载并 `delayRender`，避免首屏字体闪烁。
5. 数字用等宽或 `BebasNeue`，固定 `minWidth`，避免 CountUp 时宽度跳动。
6. `DEBUG_SAFE = true` 时画出安全区红框，方便检查。
7. `repoUrl` 允许用 `--props` 覆盖，默认 `<GITHUB_REPO_URL>`。

## 附录 C · 常见坑

| 坑 | 处理 |

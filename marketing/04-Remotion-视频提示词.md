# Remotion 视频制作提示词（竖屏 9:16 · 90s 主片）

> **怎么用**：把下面「一、任务」到「九、验收」整段复制给 AI（Claude Code / Cursor / ChatGPT 均可），
> 并把 `marketing/assets/` 一起给它。文档 05 负责配图，06 负责口播稿。
> 建议顺序：先让 AI 只搭工程 + 跑通占位图 → 再补动画细节 → 最后换真实素材。

---

## 一、任务

用 **Remotion 4.x + TypeScript** 制作一条 **90 秒竖屏 9:16** 的产品宣传片，项目名 `recbean-promo`。

主题：**「市面 600~700 的录音豆，我花 65 块自己做了一个，而且完全开源。」**

片子要给谁看：抖音 / 小红书上的**硬件 DIY、开源、AI 工具**爱好者。
目标不是「功能罗列」，而是让人看完产生三个反应：
1. 「65 块？真的假的」→ 好奇
2. 「它居然能自己醒、自己录、自己传」→ 理解
3. 「代码开源，我也想搞一个」→ 行动

交付物：
- 一条 90s 主片（1080×1920 / 30fps）
- 一张封面静帧（第 0 帧，可直接当抖音封面）
- 一条 45s 短版（见附录 A，同一套场景裁剪）

## 二、硬性规格

| 项 | 值 |
|---|---|
| Composition ID | `RecBeanPromo` |
| 分辨率 | 1080 × 1920（9:16） |
| 帧率 | 30 fps |
| 时长 | 90.0s = **2700 帧** |
| 编码 | H.264 / yuv420p / CRF 18 |
| 语言 | 简体中文（字幕 + 大字），可留英文小字点缀 |
| 输出 | `out/recbean-promo.mp4`，目标 < 80MB |

**安全区（必须遵守，抖音/小红书 UI 会挡）**：

- 顶部留 **220px**，底部留 **320px**，左右各留 **80px**
- 所有文字必须落在安全区内；装饰元素可以出血
- 字幕基线不高于 y=1600，字号 56~72px，单行 ≤ 12 个汉字，最多 2 行

**节奏硬约束**：

- 前 3 秒必须有 3 次以上视觉变化（价格卡 / 划掉 / 数字爆炸）
- 全片**任何静止画面不超过 2.5 秒**（缓推、位移、闪烁都算动）
- 转场以**硬切**为主，最多 3 次 0.12s 白闪 / 横向扫过；**不要** 3D 翻页、粒子爆炸、镜头光晕滥用

## 三、视觉系统

```ts
// src/theme.ts
export const C = {
  bg:      '#0A0B0D',   // 深空黑
  panel:   '#15181C',   // 卡片底
  line:    '#2A3038',   // 描边
  text:    '#F2F5F7',   // 主文字
  dim:     '#8A939E',   // 次要文字
  cyan:    '#00E5C0',   // 科技/正确/成功
  orange:  '#FF7A1A',   // 便宜/自造/强调
  red:     '#FF3B30',   // 问题/价格/错误
  green:   '#38D97A',   // 修复/完成
};
```

- **字体**：`@remotion/google-fonts/NotoSansSC`，字重 700 / 900；数字用 `BebasNeue` 或 `Oswald` 做价格/计数。
- **背景**：深空黑 + 极淡网格（`opacity 0.18`）+ 缓慢漂移（每帧位移 0.05px），全片统一，营造「工程感」。
- **卡片**：圆角 24px，`backgroundColor: C.panel`，`border: 1px solid C.line`，内边距 40px。
- **强调**：关键词单独换色 + `scale` 弹一下（spring，damping 200），不要整段变色。
- **禁止**：纯白底、渐变紫蓝「AI 风」、emoji 堆砌、超过 3 种主色同屏。

| 场景 | 素材 |

| S03 | `assets/photos/p01-hero.png`、`assets/photos/p10-lifestyle.png` |

| S06 | `assets/videos/v01-voice-trigger.mp4` → fallback `assets/frames/f01-voice-trigger.png`；`v02` → `f02` |

## 五、分镜表（逐帧，必须严格对齐）

> 屏幕文字 = 留在画面上的字；口播稿见 `06-旁白与字幕脚本.md`，不要在这里自由发挥。

### S05 · 它怎么工作（810–1140f / 11.0s）

六个节点沿圆形排布（半径 300，居中）：

```
深睡 → 声音唤醒 → VAD 确认 → 写卡 → 上传 → 回睡
```

| 帧 | 画面 | 动效 |
|---|---|---|
| 810–960 | 六个节点依次点亮（每 25f），一个青色光点沿圆环匀速走一圈 | 光点用 `offsetPath` 或手动 `sin/cos` 计算 |
| 960–1040 | 从「VAD 确认」拉出一条**红色虚线**分支 →「冷却 20s」→ 回到「深睡」 | 虚线 `stroke-dashoffset` 动画 |
| 1040–1140 | 大字：**误触发？先确认，再冷却，不留垃圾文件** | 关键词「确认」「冷却」分别青色/橙色 |

- 节点：圆 88px，`C.panel` 底 + 1.5px 描边；点亮后填充 `C.cyan` 10% + 文字变白
- 音效：节点 `pulse`，分支 `error`（低沉）

## 六、工程结构与实现要求

```
recbean-promo/
├── public/
│   ├── assets/…            # 从 marketing/assets 拷入
│   └── audio/              # bgm.mp3, sfx/*.mp3（可选，见第七节）
├── src/
│   ├── index.ts            # registerRoot
│   ├── Root.tsx            # Composition: RecBeanPromo / RecBeanPromo45
│   ├── theme.ts
│   ├── config.ts           # SHOT_READY / FIT / SAFE
│   ├── components/
│   │   ├── Backdrop.tsx    # 网格 + 漂移 + 暗角
│   │   ├── Caption.tsx     # 安全区字幕，2 行，自动换行
│   │   ├── BigText.tsx     # 大字，逐字上浮
│   │   ├── CountUp.tsx     # 数字滚动（支持小数/前缀）
│   │   ├── KenBurns.tsx    # 静帧缓推
│   │   ├── PhoneFrame.tsx  # 手机外框
│   │   ├── Tag.tsx         # 胶囊标签
│   │   ├── BugCard.tsx     # S08 卡片（含打字机）
│   │   └── ProgressRow.tsx # S09 进度条
│   └── scenes/
│       ├── S01Hook.tsx  …  S10CTA.tsx
```

实现约束：

1. 每个 Scene 导出 `{ durationInFrames, component }`，由 `Root.tsx` 用 `<Series>` 或 `<Sequence>` 拼接，**不要**把所有逻辑塞一个文件。
2. 动画统一用 `spring({ frame, fps, config: { damping: 200, mass: 0.6 } })` 和 `interpolate(..., { easing: Easing.out(Easing.cubic), extrapolateLeft: 'clamp', extrapolateRight: 'clamp' })`。
3. 所有时间以**帧**为单位，禁止在组件里用 `setTimeout` / CSS `animation`（Remotion 渲染不认）。
4. 中文字体通过 `loadFont()` 加载并 `delayRender`，避免首屏字体闪烁。
5. 数字用等宽或 `BebasNeue`，避免 CountUp 时宽度跳动（固定 `minWidth`）。
6. 加一个 `DEBUG_SAFE = false` 开关：为 `true` 时画出安全区红框，方便检查。
7. 提供一个 `--props` 可覆盖的 `repoUrl`，默认 `<GITHUB_REPO_URL>`，方便你换仓库地址不用改代码。

## 七、音频

| 类型 | 文件 | 说明 |
|---|---|---|
| BGM | `public/audio/bgm.mp3` | 120–128 BPM 电子/lo-fi，无 vocals；音量 0.18 |
| 口播 | `public/audio/vo.mp3`（可选） | 若你自己配音/TTS，整段铺入，音量 0.9 |
| SFX | `public/audio/sfx/{impact,whoosh,coin,click,pop,tick,cash,error,success,riser}.mp3` | 见分镜表标注 |

- **音频可能不存在**：用 `AUDIO_READY` 开关包一层，缺失时静默跳过，不能让 render 报错。
- 有口播时做 ducking：口播段 BGM 降到 0.06，用 `interpolate` 按帧算 `volume`。
- S06 的 V01 原声必须保留（`muted={false}`），这是「真实感」的核心。

## 九、验收标准（逐条自查）

- [ ] `npx remotion render` 一次通过，无 `delayRender` 超时
- [ ] 时长 **2700 帧 / 90.0s**，30fps，1080×1920
- [ ] 第 0 帧单独导出后，作为封面**信息完整**（能看到 ¥699 和价格卡）
- [ ] 全片没有连续 2.5s 以上的静止画面
- [ ] 所有文字在安全区内（打开 `DEBUG_SAFE` 检查一遍）
- [ ] **静音观看也能看懂**（字幕覆盖所有关键信息）
- [ ] 仓库地址出现 ≥ 3s，字号 ≥ 48px
- [ ] 没有出现具体竞品品牌名
- [ ] 输出文件 < 80MB，`ffprobe` 显示 yuv420p / 30fps
- [ ] 手机竖屏实看一遍：顶部/底部 UI 不遮挡文字

## 十、不要做的事

- 不要用 3D 产品渲染冒充实物；概念图必须标「概念图」。
- 不要编造测试数据（22.3s、121 条、10/10 这些是真实的，可以用；别的别加）。
- 不要说「全球首款」「吊打 XX」。

- 不要把口播稿改成营销黑话（「赋能」「闭环」「生态」一律不要）。

## 附录 C · 常见坑

| 坑 | 处理 |
|---|---|
| 中文字体没加载，渲染成方框 | `loadFont` + `delayRender`，并在 `remotion.config.ts` 设 `--gl=angle` 之外的默认即可 |
| `<Img>` 首帧空白 | 必须用 Remotion 的 `<Img>`，别用 `<img>` |
| 视频素材没到时 render 报错 | `SHOT_READY` 开关 + poster 降级 |
| 抖音压缩后文字发虚 | 字号 ≥ 56px，字重 900，避免细体 |
| 首帧黑屏 | S01 第 0 帧就要有完整构图，不要从全黑淡入 |
| 音频文件缺失导致失败 | `AUDIO_READY` 开关包住 `<Audio>` |
| CountUp 数字宽度跳动 | 容器固定宽度 + `fontVariantNumeric: 'tabular-nums'` |

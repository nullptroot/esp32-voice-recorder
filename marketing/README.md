## 4. 三条内容红线

1. **别把「硬件跑通」说成「产品完成」**。画板还没画。
2. **别编数字**。22.3s 唤醒上传、121 条记录、10/10 连录 是真实实测；续航、误触发率**没测**，不要给。
3. **AI 图别装实拍**。概念图标「概念图」；接线图必须实拍，否则观众照着接会烧板子。

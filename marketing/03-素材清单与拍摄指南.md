# 素材清单与拍摄指南

> 目标：你（或手机）按这份清单补素材，补齐后**直接覆盖同名文件**，Remotion 工程不用改代码。
> 目录：`marketing/assets/`，机器可读清单：`marketing/assets/manifest.json`。
>
> ⚠️ **当前形态：模块 + 杜邦线，没有外壳、没有电池、没有画板。**
> 所有镜头都不要拍出「成品感」；唯一允许的成品图是 P05「未来 PCB 概念图」，且必须标「概念图」。

---

## 1. 目录总览

```
marketing/assets/
├── photos/     16 张照片占位（真实 PNG，1080 宽，可直接渲染）
├── frames/      7 张视频静帧占位（视频没补齐时用它 + 缓推镜头顶着）
├── videos/      7 个 *.mp4.placeholder 规格说明（真实 mp4 你自己放进来）
└── manifest.json  全部素材的尺寸/时长/用途/状态
```

**占位图已按真实尺寸生成**，上面写明了 ID、标题、规格。可以先用它跑通 Remotion 整条片子，
后面只替换文件，不动时间轴。

### 订单截图怎么拍（P11–P14）

这是「65 块」唯一的硬证据，别马虎：

1. 打开购物 App 的**订单详情页**，能看到商品名 + 单价 + 数量。
2. **必须打码**：姓名、电话、地址、订单号后四位。只留商品、价格、下单时间。
3. 截图后用系统相册裁掉状态栏和底部按钮，只留订单内容。
4. 四张分别覆盖：主控/麦克风、声音检测/存储、电源/电池、杂项。
5. 如果总价对不上 65，**不要改图**——在视频里说「加上运费/家里现成的线材，总共不到一百」，诚实反而加分。

### 照片拍摄通用要求

- **方向**：竖构图优先（9:16），主体居中偏上，底部 1/4 留空给字幕。
- **光**：单一侧光 + 一块白纸反光，别用机顶直闪；背景用深灰/黑卡纸。
- **镜头**：手机 2× 或 3× 长焦拍特写，减少畸变；微距用 1× 贴近但别遮光。
- **参数**：锁定曝光/白平衡，关 HDR、关美颜、关人像虚化（后期统一处理）。
- **画面干净**：桌面只留素材，别出现充电线、纸巾、外卖盒。
- **多拍**：每个资产拍 5~8 张（横竖都拍），挑一张替换占位。

| ID | 期望文件 | 时长 | 用在哪 | 内容 | 拍法 |
|---|---|---|---|---|---|
| V01 | `videos/v01-voice-trigger.mp4` | 12s | 63–77s | 拍手/说话 → 设备自动开始录 | 手机竖拍，一镜到底，保留环境声；开头先静 2s 再出声，方便剪 |

| V06 | `videos/v06-soldering-pins.mp4` | 20s | 30–42s | 焊排针全过程：上锡 → 插针 → 逐针焊 → 检查 | 手机俯拍或侧拍，**固定机位**，4K 60；可 2× 加速到 10s |

### 视频拍摄通用要求

- **一镜到底 > 剪辑**：真实感来自「没剪」，尤其是 V01/V04。
- **保留原声**：V01 的环境声就是证据，别配 BGM 盖掉（BGM 后期在 Remotion 里加）。
- **首尾各留 1s 静止**：方便做淡入/卡点。
- **手不要入画太久**：V04 可以，V01 尽量只出现一下。
- **别开美颜/防抖过度**：画面会「果冻」。
- **文件命名严格一致**：`v01-voice-trigger.mp4`，小写，连字符。

### 焊排针怎么拍（V06）

这是全片最有「手工感」的镜头，拍好了比任何参数都有说服力。

1. **机位固定**：手机夹在支架上，俯拍 45°；不要手持，会晃到没法看。
2. **一次拍完**：从上锡到最后一针，中间不停机；后期 2× 加速到 10s。
3. **对焦锁死**在焊盘平面，光圈尽量小（手机就锁焦点别乱跑）。
4. **光**：侧上方一盏台灯，让焊点有反光；别逆光，烟会糊成一片。
5. **收声**：保留烙铁接触焊盘的「滋」声，这是 ASMR 级的加分项。
6. **安全**：开窗/开风扇，别拍到脸凑太近；焊完再收工位。

拍完顺手补两张：`P15` 工位、`P16` 焊好的排针特写。

### 如果暂时没有真视频

用 `frames/` 里的静帧 + Remotion 的缓推（Ken Burns）顶着，完全能出片；
把 `src/config.ts` 里的 `SHOT_READY.V01 = true` 打开后，再自动切换到真实视频。

## 4. 替换流程（3 步）

1. 用真实文件覆盖同名文件：
   - 照片 → `assets/photos/pXX-*.png`（**保持同名、同尺寸**；不同尺寸 Remotion 里会 `objectFit: cover` 兜底）
   - 视频 → `assets/videos/vXX-*.mp4`
   - 配音 → `assets/audio/vo-01.wav … vo-12.wav`（命名见 `narration/`）
2. 把 `assets/` 整个拷到 Remotion 工程的 `public/assets/`，音频拷到 `public/audio/`。
3. 在 `src/config.ts` 把对应 `SHOT_READY.Vxx` / `AUDIO_READY` 改成 `true`（照片不需要开关）。

> 改了尺寸？在 `config.ts` 里把 `FIT` 改成 `cover` 即可，不用改时间轴。

## 5. 拍摄前检查表

- [ ] 桌面清空，背景用深色卡纸
- [ ] 手机电量 > 50%，存储 > 5GB
- [ ] 关通知、关自动亮度、开飞行模式（录屏时）
- [ ] 锁定曝光/白平衡/对焦
- [ ] LM393 DO 已插回 GPIO15（否则不会响应声音）
- [ ] 设备已连 WiFi，IP 已记下（串口日志 `获得 IP`）
- [ ] 后端已启动（`cd backend-min && ./run.sh`）
- [ ] 焊接：烙铁预热到 350℃、焊锡/助焊剂就位、开窗通风
- [ ] 订单截图：已打码姓名/电话/地址/订单号
- [ ] 先试拍 10s 回放，确认对焦和声音

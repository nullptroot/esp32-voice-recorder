# 素材清单与拍摄指南

> 目标：你（或手机）按这份清单补素材，补齐后**直接覆盖同名文件**，Remotion 工程不用改代码。
> 目录：`marketing/assets/`，机器可读清单：`marketing/assets/manifest.json`。

---

## 1. 目录总览

```
marketing/assets/
├── photos/     10 张照片占位（真实 PNG，1080 宽，可直接渲染）
├── frames/      6 张视频静帧占位（视频没补齐时用它 + 缓推镜头顶着）
├── videos/      6 个 *.mp4.placeholder 规格说明（真实 mp4 你自己放进来）
└── manifest.json  全部素材的尺寸/时长/用途/状态
```

**占位图已按真实尺寸生成**，上面写明了 ID、标题、规格。可以先用它跑通 Remotion 整条片子，
后面只替换文件，不动时间轴。

### 照片拍摄通用要求

- **方向**：竖构图优先（9:16），主体居中偏上，底部 1/4 留空给字幕。
- **光**：单一侧光 + 一块白纸反光，别用机顶直闪；背景用深灰/黑卡纸。
- **镜头**：手机 2× 或 3× 长焦拍特写，减少畸变；微距用 1× 贴近但别遮光。
- **参数**：锁定曝光/白平衡，关 HDR、关美颜、关人像虚化（后期统一处理）。
- **画面干净**：桌面只留素材，别出现充电线、纸巾、外卖盒。
- **多拍**：每个资产拍 5~8 张（横竖都拍），挑一张替换占位。

## 3. 视频清单（6 段）

> 全部 **1080×1920 / 30fps / H.264**。手机 4K 60 拍完可下变换，但**不要用慢动作补时长**。

| ID | 期望文件 | 时长 | 内容 | 拍法 |
|---|---|---|---|---|
| V01 | `videos/v01-voice-trigger.mp4` | 12s | 拍手/说话 → 设备自动开始录 | 手机竖拍，一镜到底，保留环境声；开头先静 2s 再出声，方便剪 |
| V02 | `videos/v02-web-live-level.mp4` | 10s | 网页电平条随说话跳动，状态 recording | 手机竖屏录屏，先关通知；浏览器打开真机 IP |
| V03 | `videos/v03-upload-success.mp4` | 8s | 文件出现 `.up`，后端新增记录 | 录屏；设备页 → 后端页，两段可拼 |
| V04 | `videos/v04-sleep-power.mp4` | 8s | 万用表 µA 读数稳定 | 手机竖拍读数特写，手动对焦锁死；可后期放大数字 |
| V05 | `videos/v05-config-wake.mp4` | 8s | 点 GPIO14 → 手机刷新出网页 | 一镜到底最有说服力：手按 + 屏幕亮 |
| V06 | `videos/v06-serial-log.mp4` | 6s | 串口日志滚到关键行 | 竖屏录屏终端，字号 ≥ 24，只留 6s 有效信息 |

### 视频拍摄通用要求

- **一镜到底 > 剪辑**：真实感来自「没剪」，尤其是 V01/V05。
- **保留原声**：V01 的环境声就是证据，别配 BGM 盖掉（BGM 后期在 Remotion 里加）。
- **首尾各留 1s 静止**：方便做淡入/卡点。
- **手不要入画太久**：V05 可以，V01 尽量只出现一下。
- **别开美颜/防抖过度**：画面会「果冻」。
- **文件命名严格一致**：`v01-voice-trigger.mp4`，小写，连字符。

### 如果暂时没有真视频

用 `frames/` 里的静帧 + Remotion 的缓推（Ken Burns）顶着，完全能出片；
把 `src/config.ts` 里的 `SHOT_READY.V01 = true` 打开后，再自动切换到真实视频。

## 4. 替换流程（3 步）

1. 用真实文件覆盖同名文件：
   - 照片 → `assets/photos/pXX-*.png`（**保持同名、同尺寸**；不同尺寸 Remotion 里会 `objectFit: cover` 兜底）
   - 视频 → `assets/videos/vXX-*.mp4`
2. 把 `assets/` 整个拷到 Remotion 工程的 `public/assets/`。
3. 在 `src/config.ts` 把对应 `SHOT_READY.Vxx` 改成 `true`（照片不需要开关）。

> 改了尺寸？在 `config.ts` 里把 `FIT` 改成 `cover` 即可，不用改时间轴。

---

## 5. 拍摄前检查表

- [ ] 桌面清空，背景用深色卡纸
- [ ] 手机电量 > 50%，存储 > 5GB
- [ ] 关通知、关自动亮度、开飞行模式（录屏时）
- [ ] 锁定曝光/白平衡/对焦
- [ ] LM393 DO 已插回 GPIO15（否则不会响应声音）
- [ ] 设备已连 WiFi，IP 已记下（串口日志 `获得 IP`）
- [ ] 后端已启动（`cd backend-min && ./run.sh`）
- [ ] 先试拍 10s 回放，确认对焦和声音

## 6. 版权与合规

- 画面里不要出现品牌 logo、他人正脸、工牌、门牌号。
- 录音演示请用自己声音或环境音，不要录他人对话。
